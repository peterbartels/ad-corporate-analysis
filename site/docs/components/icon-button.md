# Icon Button

**Component:** `icon-button`  
**DEPT mapping:** Icon button  
**Used on:** 26 page(s)

Text link/button with a leading icon, used for 'Read in local language (…)' links on translated employee stories and arrow-prefixed links.

## CMS data model

| Field | Type | Required | Description |
|---|---|---|---|
| `label` | string | yes | Link text. |
| `url` | link | yes | Target, e.g. localized version of the story. |
| `icon` | string | no | Icon identifier (translate, arrow, ...). |
| `iconPosition` | string | no | Enum: left | right (observed: left). |
